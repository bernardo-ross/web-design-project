# Artist Portfolio

Projeto de criação e desenvolvimento de um website para portfólio artístico, utilizando o Wix.

Neste projeto, trabalhei principalmente com design, composição visual e personalização de páginas, explorando diferentes recursos para criar uma experiência visual mais completa e interessante.

## Sobre o projeto

O objetivo foi desenvolver um site que apresentasse o trabalho de uma artista de forma visualmente atrativa, organizada e intuitiva.

O projeto envolveu não apenas a estruturação das páginas, mas também um trabalho significativo de direção visual e personalização de elementos gráficos.

## O que foi desenvolvido

Durante o projeto, trabalhei em diferentes aspectos da construção visual do site:

- **Design de páginas:** criação e organização de layouts, seções e elementos visuais.
- **Edição de imagens:** ajustes, recortes, tratamento e adaptação de imagens para diferentes áreas do site.
- **Sobreposição de elementos:** composição de imagens, textos e elementos gráficos para criar diferentes efeitos visuais.
- **Integração de vídeos:** utilização e posicionamento de vídeos como parte da experiência visual.
- **Composição visual:** combinação de cores, tipografia, imagens e elementos gráficos.
- **Personalização de layouts:** ajustes de espaçamento, alinhamento, proporções e organização dos conteúdos.
- **Experiência de navegação:** organização das informações para tornar o site mais intuitivo.

## Ferramentas utilizadas

- Wix
- Editor visual do Wix
- Ferramentas de edição e composição de imagens
- Recursos de vídeo e elementos multimídia

## Principais aprendizados

Esse projeto ampliou minha experiência na criação de websites, principalmente na parte visual.

Pude explorar melhor conceitos de design, composição, hierarquia visual e integração de diferentes mídias em uma página web.

Também desenvolvi minha percepção sobre como pequenos detalhes de edição e organização podem transformar a apresentação de um site.
